# FastAPI Project

## Cấu trúc thư mục
- `app/`: Mã nguồn chính
- `tests/`: Test cases

## Cài đặt
1. Tạo virtual environment: `python -m venv .venv`
2. Kích hoạt virtual environment: `.venv\Scripts\activate` (Windows)
3. Cài đặt thư viện: `pip install -r requirements.txt`

## Chạy ứng dụng
`uvicorn app.main:app --reload`
